# products-service

Microsserviço responsável pelo catálogo de produtos do marketplace.

## Scripts

- `pnpm build`
- `pnpm start:dev`
- `pnpm lint`
- `pnpm docker`

## Ambiente local

1. Copie `.env.example` para `.env`, se necessário.
2. Suba o banco com `pnpm docker`.
3. Inicie o serviço com `pnpm start:dev`.
